## 一、三种打开方式

| 方式 | 怎么用 | 数据位置 |
|---|---|---|
| 网页 | 双击 `dist/麻将赛事管理.html`，Chrome / Edge / 手机浏览器打开 | 浏览器 localStorage |
| Windows EXE | 双击 `dist/exe/麻将赛事管理.exe`，整个 `dist/exe` 文件夹要一起拷 | `%APPDATA%\mahjong-tournament\data.json` |
| Android APK | 安装 `dist/apk/麻将赛事管理.apk` | 应用私有目录 `files/data.json` |

- 页面自适应手机，现场用手机登分、电脑看排名都行。
- 全部离线运行，不需要账号、不需要网络（除了以后可能加的雀魂同步）。
- EXE 首次运行如果被 Windows 拦截，点「更多信息 → 仍要运行」。

## 二、数据存在哪、怎么备份

- 网页版数据在浏览器 localStorage（键名 `mtt2_data`）。清缓存、换浏览器、无痕模式都会看不到数据。
- EXE / APK 每次改动自动写本地 JSON，并保留上一版 `data.bak.json`。
- **重要**：比赛结束后一定做一次「导出全部数据」（首页右上角 ☰ 或赛事菜单），得到一个 JSON 文件。
- 导入：首页「导入数据」→ 选择 JSON → 可选「合并」或「覆盖」。
- 旧版「好奇杯」数据（`curious_cup_data`）首次打开会自动识别并转换。

## 三、基本概念

```
赛季 Season            —— 多场比赛累计积分，可选
└─ 赛事 Tournament     —— 一场比赛
   ├─ 选手池 Players   —— 这场比赛的参赛者
   └─ 阶段 Stage[]     —— 可任意多个，按顺序进行
      ├─ 轮次 Round[]  —— 每个阶段若干轮
      │  └─ 桌 Table   —— 每桌 4 人或 3 人
      │     └─ 座位    —— 每人每局的顺位 + 点数 + 加减分
      └─ 晋级 → 下一阶段
```

- **阶段**是核心：每个阶段可以单独设置赛制、桌人数、轮数、每局局数、编排、计分、破同分、继承、晋级、积分。
- 只保存你填的原始数据（顺位、点数、加减分），积分和名次每次都按当前设置实时算。所以改配置会立刻影响结果。

## 四、完整流程

### 1. 建赛季（可选）

首页 →「＋ 新建赛季」。赛季用于多场比赛累计积分。没有赛季也能单独办赛。

### 2. 建赛事

首页 →「＋ 新建赛事」→ 填名字、选赛季。

### 3. 导入选手

进入赛事 → 左侧「选手池」→「＋ 批量导入选手」：

- 一行一个：`名字` 或 `雀魂UID 名字`
- 重复名字会自动跳过
- 可选来源：直邀 / 预选 / 外卡 / 手动
- 也可以「从其他赛事导入」「从赛季直邀导入」
- 要批量删：勾选行首复选框 →「删除选中（N）」；表头复选框可全选

### 4. 添加阶段

顶部步骤条 →「＋ 添加阶段」：

- **积分赛**：多轮累计，适合预选/循环
- **单败淘汰**：输一次即淘汰
- **双败淘汰**：胜者组/败者组

一个赛事可以有任意多个阶段，比如「预选（积分赛）→ 本战（积分赛）→ 决赛（单败）」。

### 5. 配置阶段

进入阶段 →「配置」标签，逐项设置（详见下一节）。

### 6. 开始第 1 轮

「编排登分」→「🎲 开始第 1 轮（自动分桌）」。系统按配置自动分桌。

### 7. 登分

每桌一张表，逐行录：

- 第 1 局顺位 / 点数、第 2 局顺位 / 点数……（局数由阶段设置决定）
- 加分 / 扣分 / 迟到 / 缺席（手动修正）
- 右侧实时显示：**小分**、**轮修正**、**本轮总分**、**顺位**

录完点「✔ 确认第 N 轮」。确认后本轮只读；要改先「↩ 回退」。

### 8. 下一轮

确认后点「＋ 开始第 N+1 轮」。到设定轮数后会提示已完成全部轮次。

### 9. 看排名

「排名」标签：总分、小分、修正、均顺位、1~4 位次数。可手动改「修正」、用 ↑↓ 手动调名次。

### 10. 生成晋级

「排行」页 →「✔ 生成晋级名单」，或「晋级/结果」页。按晋级规则挑选，自动同步到下一阶段的参赛者。

### 11. 下一阶段 / 结束

- 有下一阶段：点「去下一阶段」
- 没有：点「＋ 添加下一阶段」，或「设为赛事结果」→「完成赛事」
- 完成后赛事进入赛季积分榜

## 五、阶段配置逐项说明

### 基础

| 项 | 说明 |
|---|---|
| 阶段名称 | 随便改 |
| 赛制 | 积分赛 / 单败淘汰 / 双败淘汰 |
| 每桌人数 | 4 人或 3 人 |
| 轮数 | 本阶段一共几轮 |
| 每轮局数 | 每轮打几个半庄（1~12） |

> 改桌人数/局数/赛制会清空本阶段已有轮次，会先弹窗确认。

### 积分赛编排

| 项 | 说明 |
|---|---|
| 默认编排方式 | 随机 / 高高碰 / 分层抽签 / 分档抽签 / 循环赛 / 按上阶段名次 |
| 并存回退链 | 主编排之外再勾几种；每轮分别排一次，自动选「重复同桌最少」的方案 |
| 首轮种子来源 | 随机 / 上阶段名次 / 按选手顺序 |
| 避免重复同桌 | 尽量 / 严格 / 不避免 |
| 分层人数 | 分层抽签每层人数 |
| 人数不整除时 | 轮空 / 3 人桌 / 补幽灵位 |
| 循环赛分组 | 分几个小组循环 |

轮次信息里会显示本轮实际用了哪种编排、重复了几对同桌。

### 计分

| 项 | 说明 |
|---|---|
| 计分方式 | 排名分制 / 纯分数 + 修正 |
| 排名口径 | 桌内排名 / 全场排名 |
| 正分名次分表 | 4 人桌、3 人桌各一套（水上用） |
| 负分名次分表 | 同上（水下用） |
| 名次分择表依据 | 按个人正负分 / 按桌上正分人数（二选一） |
| 名次分来源 | ☑ 每轮 / ☑ 每局，可同时勾，两笔相加 |
| 并列平分 | 并列时平分几人占用的名次分档位 |
| 录入口径 | 原始点数 / 含名次修正的点数（反推小分） |
| 水上/水下修正 | 按本轮总分与阈值加减 |
| 轮空得分 | 轮空者每轮固定得分 |
| 手动修正栏 | 是否显示加分/扣分/迟到/缺席 |

### 破同分规则

可增删、上下排序。支持：总原始分、每局顺位总和、每局均顺位、每轮均顺位、一位数、二位数、三位数、垫底数、一位率、垫底率、直接对局、轮空数、报名种子、抽签。

### 分数继承

从上一阶段带来的分数：清零 / 全部继承 / 按比例。会加到本阶段总分里（单独显示「传承」）。

### 阶段积分

见[赛季积分](#九赛季积分)。

### 晋级下一阶段

- 取前 N 名
- 达到分数线
- 两者组合（达标必进，不满 N 人再按名次补）

## 六、计分规则详解

### 6.1 排名分制

每一轮（或每一局）：

1. 按点数排名
2. 查名次分表得到名次分
3. 本轮名次分相加 = 总积分

```
总积分 = Σ每轮名次分（可含每局名次分）
小分   = Σ各局原始点数   （不含任何修正）
```

### 6.2 纯分数 + 修正

```
本轮原始 = Σ本局点数
轮修正   = 名次修正 + 水上水下 + 加分 − 扣分
本轮总分 = 本轮原始 + 轮修正
小分     = Σ各局原始点数（不含修正）
```

- 名次修正来自名次分表（可只算每轮、只算每局、或两者都算）
- 录入口径选「含名次修正的点数」时，填的是加过名次修正后的分数，系统反推原始点数当小分

### 6.3 名次分表怎么填

- 4 人桌：填 4 个数，从第 1 名到第 4 名
- 3 人桌：填 3 个数
- 例：`50,10,-10,-30`
- **只给第一名奖励**：`15,0,0,0`
- 并列且勾了「并列平分」：2 人并列第一，各得 (15+0)/2 = 7.5

### 6.4 正分 / 负分两套表

每个选手按**自己本轮（或本局）原始点数的正负**选表：

- ≥ 0 用「正分名次分表」
- < 0 用「负分名次分表」

两套表默认相同，需要区分时再改负分表。

### 6.5 按桌上正分人数选表

「名次分择表依据」还可以切换到 **按桌上正分人数**：

- 先数这一桌里原始点数 ≥ 0 的有几个人（k）
- 整桌用 `k` 对应的那套名次分表
- 4 人桌配 k = 0/1/2/3/4 五套；3 人桌配 k = 0/1/2/3 四套
- 每桌各自统计，不同桌可以用不同表
- 每局/每轮都按各自口径统计

两种依据互斥，一个阶段只能选一种。

### 6.6 小分与轮修正的区别（重要）

- 轮修正（名次分、水上水下、加分扣分）**只进本轮总分**，不进小分
- 小分永远是纯点数之和，用于破同分「总原始分」

## 七、淘汰赛

### 单败

- 每桌晋级 1 或 2 人
- 首轮按上阶段名次蛇形落座（1、8、9、16 一桌这种）
- 自动生成轮次，直到只剩一桌决赛
- 决赛桌打完即出最终名次

### 双败

- 每桌前 2 进胜者组、后 2 进败者组
- 可设「初始直接进败者组的人数」（按上阶段名次从末位取）
- 胜者组决赛桌、败者组决赛桌各打一场
- 总决赛默认 4 人桌：胜者组决赛桌前 2 + 败者组决赛桌前 2
- 也可改成「两组冠军同桌」

### 淘汰赛的分数

- 默认每轮清零，只看本轮总分
- 可在配置里开「轮与轮之间继承分数」
- 每桌也一样有加分/扣分/迟到/缺席

### 对阵图

淘汰赛阶段有「对阵」标签，显示每桌结果与晋级情况，可导出/打印。

## 八、排名、破同分、晋级

- 排名页按「积分 → 小分 → 均顺位 → …」逐级比较
- 退赛、DQ 会沉底，DQ 不计积分
- 「修正」列是整阶段的手动加减（不影响单轮成绩）
- ↑↓ 可手动调整名次（生成晋级会按手动顺序）
- 生成晋级后，名单自动写入下一阶段

## 九、赛季积分

积分规则在**每个阶段**上设置（不用赛季统一）：

- 勾「本阶段计入赛季积分」
- 积分方式：名次分表 / 线性公式（第 1 名最高 → 末名最低）
- 「与之前阶段叠加为总积分」：开 = 累加；关 = 本阶段单独算，不进总分
- 退赛 / DQ / 未出场的得分
- 「保存为模板」可复用；任意阶段「从模板载入」

赛事总积分 = 各叠加阶段之和。赛事结果页显示明细（如「预选 30 + 本战 50」），可逐人手动覆盖。

赛季榜按赛事总积分汇总，统计范围可选「赛季全部」或「最近 N 场」，可导出榜单和直邀名单。

## 十、导入牌谱 CSV

入口：阶段 →「编排登分」→ 有未确认轮次时 →「📥 导入牌谱 CSV」。

1. 选择轮次
2. 选 CSV 文件（雀魂牌谱导出格式）
3. 预览：可导入几局、跳过几行、哪些名字没匹配到
4. 「写入成绩」按桌匹配填入空闲局位

规则：

- 按表头识别 `X位玩家`、`X位分数` 列
- 优先用 UID 匹配，其次用昵称
- 电脑/CPU 位记为缺席
- 同一桌 4 人都能匹配才导入
- 一局填一个空闲的半庄位，超出局数的会跳过

## 十二、测试用快速填分脚本

`tools/快速填分脚本.js` 用来快速造测试数据：

1. 进入阶段，开始一轮
2. F12 → Console
3. 粘贴整个脚本，回车
4. 可用命令：
   - `QCFill.fillCurrent()` 填当前轮
   - `QCFill.fillStage()` 填本阶段所有未确认轮
   - `QCFill.clearCurrent()` 清空当前轮
   - `QCFill.verify()` 自检
   - `QCFill.CFG.STEP` 改点数精度

生成的每桌每局点数和为 0，顺位自动按点数排。

## 十三、常见问题

**Q：录分格子点不动？**
A：确认当前轮还没「确认」。确认后是只读的，要改先「回退」。

**Q：改了规则，成绩要不要重录？**
A：不用。积分、名次、晋级都是实时重算的。

**Q：换电脑 / 换浏览器数据没了？**
A：网页版数据在浏览器里。用「导出全部数据」带走 JSON，到新地方「导入数据」。

**Q：重复同桌太多？**
A：配置里把「避免重复同桌」调成「严格」，或在并存回退链里加「分层抽签」。

**Q：人数不是 4 的倍数？**
A：配置里选「轮空 / 3 人桌 / 补幽灵位」，默认轮空。

**Q：3 人桌怎么计分？**
A：名次分表有单独的 3 人桌一套，按实际人数排名。

**Q：能直接连雀魂比赛场自动登分吗？**
A：方案调研见 [雀魂比赛场接入方案](雀魂比赛场接入方案.md)，目前需要另做同步器，尚未内置。

**Q：APK 怎么导出 PDF？**
A：APK 内导出会存 HTML 到「下载」，用手机浏览器打开再打印/存 PDF。
