# 麻将赛事管理 · Mahjong Tournament Manager

[![license](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![platform](https://img.shields.io/badge/platform-Web%20%7C%20Windows%20%7C%20Android-blue.svg)](#快速开始)

纯本地运行的通用麻将赛事管理系统。一个单文件网页，同时打包成 **Windows EXE** 与 **Android APK**，不需要服务器、不需要联网。

支持多阶段多赛制、四种积分赛编排、排名分与纯分数两种计分、阶段与轮次分数继承、自定义破同分链、赛季积分、牌谱 CSV 导入与多种导出。

> 📖 详细使用说明：[docs/使用说明.md](docs/使用说明.md)

- 单文件网页：[dist/麻将赛事管理.html](dist/麻将赛事管理.html)
- Windows 绿色版：[dist/exe/麻将赛事管理.exe](dist/exe/麻将赛事管理.exe)（本地构建产物，不进仓库）
- Android：[dist/apk/麻将赛事管理.apk](dist/apk/麻将赛事管理.apk)

> 数据只存在本机；浏览器里建议赛前赛后各导出一次 JSON 备份。

## 快速开始

### 1. 网页版（最快）

双击 `dist/麻将赛事管理.html`，用 Chrome / Edge / 手机浏览器打开即可。首次进入点「载入示例」可以熟悉界面。

### 2. Windows 绿色版

```
dist/exe/
  麻将赛事管理.exe      ← 双击运行
  resources/app/       ← 应用与页面
  ...
```

整个 `dist/exe` 文件夹一起拷走即可，无需安装。数据自动保存到：

```
%APPDATA%\mahjong-tournament\data.json      当前数据
%APPDATA%\mahjong-tournament\data.bak.json  上一版备份
```

首次运行若提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

### 3. Android

安装 `dist/apk/麻将赛事管理.apk`（已 v2/v3 签名）。数据保存在应用私有目录 `files/data.json`，卸载会一并删除，重要赛事请先导出。

## 核心概念

```
赛季 Season
 └─ 赛事 Tournament
     ├─ 选手池 Players
     └─ 阶段 Stage[]（可任意多个，串行）
         ├─ 赛制：积分赛 / 单败淘汰 / 双败淘汰
         ├─ 每桌人数、轮数、每轮局数
         ├─ 登分：每桌每局「顺位 + 点数」+ 手动加减
         └─ 晋级规则 → 下一阶段
```

- 只有「原始录入值」被存储（顺位、点数、加减分），积分、名次、晋级全部按当前设置实时重算；改参数立刻看到新结果。
- 每个阶段可以单独设定赛制、桌人数、局数、计分、继承、破同分与晋级规则。

## 功能说明

### 多阶段多赛制

| 赛制 | 说明 |
|---|---|
| 积分赛 | 多轮累计，按编排方式分桌；每轮可设局数；结束后按排名或分数晋级 |
| 单败淘汰 | 每桌晋级 1 或 2 人，蛇形种子落座，输一次即淘汰；自动生成轮次直到决赛 |
| 双败淘汰 | 胜者组 / 败者组并行；每桌前 2 进胜者组、后 2 进败者组；可指定若干人开局直接进败者组；**总决赛为 4 人桌**（胜者组决赛桌前 2 + 败者组决赛桌前 2），也可改为两组冠军 1v1 |

每阶段可配置：

- 每桌人数：4 人 / 3 人（三麻）
- 轮数、每轮局数（半庄数）1~12
- 人数不整除时：轮空 / 成 3 人桌 / 补幽灵位

### 积分赛编排

| 编排方式 | 做法 |
|---|---|
| 随机抽签 | 完全随机分桌（首轮常用） |
| 高高碰 | 积分降序后滑动窗口配对，桌内分数接近；深度避免重复同桌 |
| 分层抽签 | 按当前排名每 N 人一层，层间交叉组桌 |
| 分档抽签 | 按赛前给选手打的档位（S/A/B/C…）抽签组桌 |
| 循环赛 | 轮转排桌，每轮人人出赛，优先安排没同桌过的人 |
| 按上阶段名次 | 按上一阶段排名蛇形落座 |

**多种并存**：阶段可设「默认编排 + 并存回退链」。每轮会分别用主编排和回退链各排一次，自动选「重复同桌最少」的方案，并在轮次信息里显示本轮用了哪种编排、重复了几对。

### 计分方式

两种计分都记录「顺位 + 点数」，都支持手动修正栏。

#### 排名分制

- 每轮按**桌内**总分排名（也可切全场排名），按名次分表给分，累加为积分。
- **名次分来源**可勾选，两者能共存：
  - `每轮`：几个半庄的总分排名后给一次名次分。
  - `每局`：每个半庄各自按顺位给一次名次分。
  - 两个都勾 = 两笔名次分相加。
- 名次分表对 4 人桌、3 人桌分别配置，例如 `50,10,-10,-30`；并列可「平分档位」。
- 每轮总分作为**小分**参与破同分。
- 名次分表直接包含「第一名奖励」：要只给 1 位发分，就把 1 位填 15、其余填 0；并列时按「并列平分名次分」摊分。

#### 纯分数 + 修正

- 每轮总分直接累计，可叠加：
  - 名次修正（把名次分表当修正用）
  - 水上 / 水下修正（按本轮总分与阈值加减）
  - 手动加分 / 扣分
- **录入口径可切换**：
  - `原始点数`：填原始点数，修正由系统加。
  - `含名次修正的点数`：填已经加过名次修正的点数，系统用「录入值 − 名次修正」**反推原始点数**，作为破同分小分。

#### 手动修正栏

每桌每位选手都有：加分、扣分、迟到、缺席，以及整阶段的「修正」栏（在排名页）。轮空可设固定得分。

#### 小分与轮修正

- **轮修正**（名次分、水上水下、加分/扣分）只加到「本轮总分」，不进入小分。
- **小分 = 各局原始点数之和**，破同分用的就是它。
- 每轮局数任意（1~12），名次分按每轮/每局的规则都在该局数下正常累加。

### 破同分规则

可自由增删、上下排序的比较链，支持：

`总原始分` · `每局顺位总和` · `每局均顺位` · `每轮均顺位` · `一位数` · `二位数` · `三位数` · `垫底数` · `一位率` · `垫底率` · `直接对局` · `轮空数` · `报名种子` · `抽签`

### 分数继承与晋级

- **阶段之间**：清零 / 全部继承 / 按比例继承，计入下一阶段总分。
- **淘汰赛轮与轮之间**：可单独开启继承。
- **晋级规则**：取前 N 名 / 达到分数线 / 两者组合。
- 每轮确认后只读，可回退重算；支持手动排名（↑↓ 调整）、手动换座、换人、手改分桌。
- 退赛 / 取消资格（DQ）实时生效：不占晋级名额、排名沉底，已打成绩保留。

### 赛季积分

- 积分规则在**每个阶段**上单独设置（每场比赛各自配），不再一个赛季一套。
- 阶段积分方式：名次分表，或线性公式（第 1 名最高、末名最低）。
- **叠加开关**：每个阶段可勾选「与之前阶段叠加为总积分」；关闭则本阶段积分单独计算，不计入赛事总分（只用于本阶段排名/晋级）。
- 特殊情况分：退赛 / DQ / 未出场 分别给分。
- 常用规则可「保存为模板」，任意阶段「从模板载入」。
- 赛事总积分 = 各叠加阶段之和；可在赛事结果页逐人手动覆盖并恢复自动。
- 赛季榜汇总赛季内各赛事总积分；统计范围可选「赛季全部」或「最近 N 场」，可导出赛季榜与直邀名单。

### 导入导出

| 功能 | 说明 |
|---|---|
| 选手批量导入 | 一行一个：`名字` 或 `UID 名字`；去重；可标记来源（直邀/预选/外卡/手动） |
| 从其他赛事导入 | 复制其他赛事的选手名单 |
| 从赛季直邀导入 | 按赛季积分榜前 N 名导入 |
| 雀魂牌谱 CSV | 按「X位玩家 / X位分数」列解析，UID/昵称匹配选手与桌次，自动填点数与顺位；电脑位记缺席；导入前可预览匹配结果 |
| JSON 导出/导入 | 全量导出、合并导入、覆盖导入 |
| 旧版数据 | 自动识别并转换旧版「好奇杯」数据 |
| 导出成绩 | 名单、排名、晋级名单、对阵、赛季榜；可打印或另存 PDF；另有 CSV（Excel 直接打开） |

> 牌谱导入入口：阶段 →「编排登分」→ 未确认的轮次 →「📥 导入牌谱 CSV」。
> 想直接从雀魂比赛场拉取成绩，见 [docs/雀魂比赛场接入方案.md](docs/雀魂比赛场接入方案.md)。

## 使用流程

1. **新建赛季**（可选）→ **新建赛事**，选择归属赛季。
2. **选手池**：批量粘贴导入，设置来源；可改 UID / 分档。
3. **添加阶段**：选积分赛 / 单败 / 双败，填每桌人数、轮数、每轮局数。
4. **配置**：编排方式与回退链、计分方式、名次分表、破同分链、继承、晋级规则。
5. **编排登分**：开始第 1 轮自动分桌；每局录顺位与点数，必要时填加分/扣分；确认本轮后进入下一轮。
6. **排名**：查看累计排名、小分、各位次数；可手动改修正、手动调名次。
7. **晋级/结果**：生成晋级名单（自动同步到下一阶段），最后一个阶段后完成赛事。
8. **赛季**：赛季榜汇总积分、导出直邀名单。
9. 随时「导出全部数据」备份。

## 数据存储与备份

| 形态 | 存储位置 |
|---|---|
| 浏览器 | localStorage（键 `mtt2_data`） |
| Windows EXE | `%APPDATA%\mahjong-tournament\data.json`，每次改动自动写盘并保留上一版备份 |
| Android APK | 应用私有目录 `files/data.json`，同样自动备份 |

浏览器 localStorage 有容量上限且可能被系统清理，重要数据请导出 JSON。EXE / APK 会自动落盘，不受浏览器缓存清理影响。

## 从源码构建

环境：Node.js 18+。打包 EXE 需要一份 Electron 运行时；打包 APK 需要 Android SDK（build-tools 35 / platform android-35）与 JDK 17+。

```bash
node build.mjs                     # src → dist/麻将赛事管理.html（单文件）
node scripts/build-exe.mjs         # 组装 Windows 绿色版（需改脚本里的 electron 路径）
node scripts/build-apk.mjs         # aapt2 + javac + d8 + zipalign + apksigner 手工构建 APK，不走 Gradle、不联网
node scripts/serve.mjs dist 8123    # 本地预览 http://127.0.0.1:8123/
```

构建脚本里的 SDK / JDK / Electron 路径写死在文件顶部，按自己机器改一下即可。

## 已知限制

- 只处理「一桌·一局的最终结果」，不介入番符、役种、宝牌、本场等牌局过程。
- Android WebView 的系统打印不可用：导出会保存 HTML 到「下载」，再用浏览器打印成 PDF。
- 双败总决赛默认 4 人桌，可在阶段配置切换。
- 浏览器存储可能被清理，请用导出的 JSON 备份。
